# 景点图标黑边修复

省内景点图标使用的 JPG 自带实色底，原页面的大范围投影进一步放大了矩形边缘。

`2d/landmark-renderer.js` 将现有纹理绘制到网页的透明 Canvas 上，仅隐藏从画面外围连通的底色。内部深色区域增加建筑轮廓保护，避免门洞和阴影随底色一起被隐藏；浅色底素材按边缘颜色识别。原有图片文件、颜色和景点坐标保留。

进入省份时按需加载并缓存，每张显示纹理最长边限制为 1200 像素。背景显示成功后替换原有 CSS 图片，失败时保留原图。景点名称、键盘操作和点击入口沿用原逻辑；只有图标的预览弹窗也复用相同显示结果。页面投影减轻，避免在地图上出现大片暗块。

生成式透明素材试做未采用，以免重绘建筑细节。地图采用原素材的网页渲染修复。

验证脚本：`scripts/verify-landmark-rendering.cjs`，检查 39 张纹理的透明外围、有效建筑内容、原背景替换和景点预览点击，并输出福建、北京、河南、山西、天津页面截图。

省份内容回归：`scripts/verify-province-content.cjs`，覆盖 34 省份、39 图标、22 预览入口、15 空省份和 17 个现有游历页面。

后续交互优化：图标加载前隐藏原实色底，失败时恢复原图并允许下次重试；为 39 个景点增加常驻名称、悬停/键盘焦点状态说明和目录双向高亮。悬停不再改变容器高度。只有图标的预览增加加载提示，序列编号防止快速切换时的旧结果覆盖新预览。
