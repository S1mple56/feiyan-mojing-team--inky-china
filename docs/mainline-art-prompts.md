# 五大墨灵空间画面生成说明

每张画面用于主线章节的横向场景区，建议为 16:9 或 3:2 横幅。不要在图中生成文字、标识、水印、UI、边框或可读铭文；交互提示由网页叠加。

共同风格：古典中国水墨与细腻工笔结合，宣纸纹理、墨线勾勒、低饱和矿物色、可见留白与薄雾，游戏场景概念图，横向宽幅，建筑结构可信但不作为施工图。

## 黄鹤楼：未送出的告别

Use case: historical-scene  
Asset type: chapter 1 interactive game backdrop  
Primary request: 黄昏时分的黄鹤楼临江场景，楼上可见三层窗与栏杆，江面远处一艘即将离岸的小船，左下角有安静的渡口和一盏尚未点亮的岸灯；楼阁与江面之间要有明显可读的视线联系，为信纸、开窗和光路交互留出空间。  
Style/medium: 共同风格  
Composition/framing: 横向中远景，黄鹤楼靠左，江面与渡口横向延伸到右侧，中心留出交互物件区域  
Lighting/mood: 暮色停滞、温暖夕照、微雾，含克制的离别感  
Constraints: 不要人物特写，不要文字，不要水印

## 赵州桥：桥那头的人

Use case: historical-scene  
Asset type: chapter 2 interactive game backdrop  
Primary request: 墨色长河上的赵州桥，正面略低视角展现单孔石拱、桥面与桥下拱石；左桥头有旧行囊和昏暗小灯，桥中央预留可挂灯的位置，对岸被雾遮住，桥下可看见可供解谜的石块轮廓。  
Style/medium: 共同风格  
Composition/framing: 横向宽画面，桥占中部，两岸均有可读路径，前景河岸留白  
Lighting/mood: 清冷雾气中带一点金色灯光，守候与重新通路的情绪  
Constraints: 不要现代设施、不要文字、水印或边框

## 拙政园：留不住的春天

Use case: historical-scene  
Asset type: chapter 3 interactive game backdrop  
Primary request: 拙政园风格的曲廊、水院、漏窗、假山与亭角；一侧是永远盛开的春花，另一侧有静止水面、残荷和一片秋叶，画面中有四处不同形状的窗景和远处半遮挡的水闸。  
Style/medium: 共同风格  
Composition/framing: 横向游览动线，前景回廊引向中景水院和远景水闸，给四幅画与屏风互动留出干净墙面  
Lighting/mood: 初春明净、时间停滞又隐含季节变化  
Constraints: 不要人物特写，不要文字、水印或边框

## 应县木塔：无名的一层

Use case: historical-scene  
Asset type: chapter 4 interactive game backdrop  
Primary request: 应县木塔内部的一层到上层的仰视空间，梁柱、斗拱、木楼梯和榫卯连接清晰可见；入口有工具与带刻痕的木料，中景是一张简朴的操作台，上层有一束光照向营造账册。若干梁柱处以浅墨虚影表现尚未稳定的承托关系。  
Style/medium: 共同风格  
Composition/framing: 横向室内广角，纵向梁柱与上行楼梯构成清晰的视觉目标，交互物件不要被遮挡  
Lighting/mood: 深木色、尘埃光束、安静而庄重，强调被承托与无名劳作  
Constraints: 不要现代电灯、不要人物特写，不要文字、水印或边框

## 福建土楼：等你回家的灯

Use case: historical-scene  
Asset type: chapter 5 interactive game backdrop  
Primary request: 福建圆形土楼内部的环廊与中央院落，镜头位于二层环廊，沿一圈木门看向中央；三扇门分别有修补痕迹、待补灯笼和门牌轮廓，院中有一座长卷灯座，前四件信物的淡墨光影悬在灯座周围。起初门户关闭、灯光微弱，但院落中央要为最终共同灯光留出位置。  
Style/medium: 共同风格  
Composition/framing: 横向广角，环形空间与中心院落一目了然，门与灯座都具备可点击的可读性  
Lighting/mood: 傍晚蓝灰环境光，暖黄色灯火逐渐聚向中心，团聚与归属感  
Constraints: 不要文字、水印、边框，不要现代设施
